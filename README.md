# Overview
The software I made is a C# text adventure game called The Enchanted Forest. 
The player explores a magical forest, collects items, earns points, and searches for a golden treasure.
The game allows players to make different choices that affects their progress.

My Purpouse for making this software was to improve my understanding of C# programming and gain experience using variables, expressions, conditionals, loops, methods, classes, and structures. 
I also wanted to practice reading and writing files by allowing players to save and load their progress.
